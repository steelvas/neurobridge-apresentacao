O que acontece depois de clicar em Salvar?

Python é a linguagem que expressa as regras da aplicação. Streamlit é a ferramenta que transforma instruções Python em campos e botões no navegador.

Dois trechos do programa

1. Receber o clique

salvar = formulario.form_submit_button("Salvar preferências")
Ver trecho no app.py

Ao clicar em Salvar preferências, o formulário envia o conjunto de respostas. O programa confere apelido, turma e duplicidades antes de criar ou atualizar a ficha.

2. Calcular a porcentagem

percentual = quantidade / total * 100
Ver trecho no app.py

Com 8 escolhas em 20 formulários autorizados, o cálculo é 8 ÷ 20 × 100. O painel mostra 40%.

Como o Python decide e repete?
if quantidade > 0:
    percentual = quantidade / total * 100
Ver trecho no app.py

if significa “se”. Os espaços à esquerda colocam o cálculo dentro da condição. O resultado é exibido quando houve ao menos uma escolha.

Como executar e o que aparece?

Na pasta do repositório, com Python 3.11 ou superior, execute um comando de cada vez no terminal.

python -m pip install -r neurobridge.developed/requirements.txt
python -m streamlit run neurobridge.developed/app.py

O terminal informa o endereço Local URL. Abra-o no navegador e mantenha o processo em execução. Surgem as áreas Formulário do aluno, Cadastros e Painel do professor.

Em cada volta, enumerate fornece a posição e o texto da pergunta. O seletor exibe as opções daquela linha. A lista de respostas guarda a posição da escolha feita pelo estudante.

Por que há um while no cálculo dos minutos?
while faltam > 0:
    maior = 0
    for indice in range(1, len(restos)):
        if restos[indice] > restos[maior]:
            maior = indice
    minutos[maior] = minutos[maior] + 1
    restos[maior] = -1
    faltam = faltam - 1
Ver trecho no app.py

Quando a divisão produz minutos fracionados, o programa começa pelas partes inteiras. Enquanto sobram minutos, acrescenta um ao formato com maior resto disponível. Assim, a proposta fecha na duração da aula.
